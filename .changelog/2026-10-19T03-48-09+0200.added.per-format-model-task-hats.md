# Per-format model task hats

Model testing probes each API format (generate → chat/completions, embedding,
score → rerank, moderation, decision → systemone) and stores passing hats as
`tasks`. Missing provider `task` starts with generate/chat. Decision uses a
valid System One probe body and is only tried when advertised, so other models
are not false-labelled. Enabled if any format works; the drawer shows chips and
`GET /v1/models` exposes verified `tasks`.
