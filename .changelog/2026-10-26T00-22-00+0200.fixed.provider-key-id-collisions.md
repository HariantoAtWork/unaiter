# Fix duplicate API key ids swallowing new keys

Key ids were only unique by accident: bulk paste took whatever id the line
carried (`all|oc_sk_…`), while delete, move, exhaust, proxy rotation and the
Vue list keys all address keys by id. Pasting a second key under an existing
id saved it, but the old entry kept answering for that id — and removing one
key deleted every key sharing the id.

Ids are now unique per provider: a taken id becomes `all-2`, `all-3`, …,
existing stores are normalised on read, and delete removes exactly the one
entry it matched.
