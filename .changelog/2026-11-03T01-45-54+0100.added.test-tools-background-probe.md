# Test tools button with background SSE probe

Format testing alone does not show whether a model can call tools. The models
drawer now has **Test tools** beside **Test models**: it enqueues the same
per-provider SSE job queue with `kind: tools`, forces a `ping` tool call over
`chat/completions`, and stores `tools: true|false` on each catalogue row
without flipping enablement. Passing models show a `tools` chip; `GET /v1/models`
exposes the flag after a probe.
