Added a local Nuxt module at `plugins/router` (dns01-proxy-style) for intent routing. Admins configure a classifier plus writing/code specialists at `/router`; clients call `router/auto` on `/v1/chat/completions` and Una Iter classifies the request, then proxies it to the matching specialist. The planner can return several writing/code steps, so multi-part prompts (e.g. a poem and then JS) run specialists in parallel and merge sectioned answers, while single-step requests still stream through one specialist. Includes config API endpoints, shared types/defaults, and wiki updates.
